# Рутина repo-janitor в Кузнице

Готовый пайплайн: [`repo-janitor-routine.pipeline.json`](repo-janitor-routine.pipeline.json) — собран из
[`benchmark/ROUTINE.md`](https://github.com/YpCIIIaK/repo-janitor/blob/main/benchmark/ROUTINE.md) импортом
«Порядок действий из Markdown».

## Что внутри

```
Задача → 0.5 Tracks → 1.1 Add repos → 1.2 Scan → 1.3 Label → 1.4 Fix false-positive clusters
       → 1.5 Verify → 1.6 Refresh and ship → 1.7 Bring every result up to date → Random layer draws
       → Отчёт → Проверка отчёта → Сохранить отчёт → Результат
```

- **Шаги** — агенты с чтением и правкой файлов, поиском по коду, терминалом и вебом. Каждый получает
  текст своего раздела ROUTINE.md и итог предыдущего шага.
- **Правила** (раздел «0. Ground rules»: ветка `bench/<date>-<n>`, без force-push, не трогать скоринг,
  не ослаблять проверки и т. д.) — в системном промпте каждого шага.
- **Отчёт** заполняет шаблон из раздела «2. Report (PR body)» по реальным результатам шагов.
- **Проверка отчёта** сверяет его с чек-листом «3. How a reviewer checks a cycle»; при замечаниях
  отчёт переписывается один раз.
- **Сохранить отчёт** — в `benchmark/cycle-report.md` рабочей папки.

## Как запустить

1. **Склонируйте repo-janitor** к себе: `git clone https://github.com/YpCIIIaK/repo-janitor`.
2. **Настройки → Рабочая папка и терминал**: рабочая папка — путь к этому клону, терминал —
   «Полный доступ». Лимит времени на команду поднимите до 1800 с: сканирование долгое
   (длинные прогоны модели запускают в фоне через `start_process`).
3. **Модель.** Все шаги стоят на роли «Умная». Выберите её в Настройках → Роли моделей — лучше
   по подписке, например `Claude Opus 5.5 · подписка` с усилием `high` или `max`, или
   `GPT-6.1-Sol · подписка`. Бесплатные модели OpenRouter с такой рутиной, скорее всего,
   не справятся. Модель отдельного шага можно сменить в редакторе (клик по блоку → инспектор).
4. **Кузница → Импорт → Пайплайн из JSON-файла** → выберите `repo-janitor-routine.pipeline.json`.
5. В поле «Вход» напишите задачу цикла, например:
   `Цикл 2026-11-12-1, трек security. Добавь 100 репозиториев, разметь не меньше 60 находок.`
6. **Запустить.** Включите «Пошагово», чтобы проверять результат каждого шага перед следующим.
   Готовый отчёт появится в «Результате» и в `benchmark/cycle-report.md`.

Из чата: кнопка **В чате** в редакторе пайплайна открывает диалог, где эта рутина — участник;
каждое сообщение запускает всю схему.

## Обновить из свежего ROUTINE.md

Кузница → **Импорт → Порядок действий из Markdown** → ссылка
`https://github.com/YpCIIIaK/repo-janitor/blob/main/benchmark/ROUTINE.md` → **Загрузить** →
выберите модель и путь отчёта → **Создать пайплайн**.
