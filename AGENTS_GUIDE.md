# Руководство по вкладке "Agents"

## Обзор

Вкладка **Agents** (Агенты) объединяет два мощных инструмента:
1. **Agent Constructor** — визуальный конструктор мульти-агентных pipeline'ов
2. **Skill Manager** — менеджер навыков (skills) для агентов

## Как использовать Agent Constructor

### Создание нового pipeline

1. Перейдите на вкладку **Agents** в боковом меню
2. Убедитесь, что выбрана вкладка **Agent Constructor**
3. Нажмите кнопку **"+ New Pipeline"** в левой панели
4. Введите имя и описание pipeline
5. Нажмите **"+ Add Step"** чтобы добавить шаг (агента)

### Настройка агента (шага)

Для каждого шага можно настроить:

- **Agent Role** — роль агента:
  - `Classifier` — классификация входных данных
  - `Router` — маршрутизация по доменам
  - `Analyst` — анализ данных
  - `Researcher` — глубокое исследование
  - `Synthesizer` — синтез результатов
  - `Summarizer` — суммаризация
  - `Validator` — валидация результатов
  - `Custom` — кастомная роль

- **Model** — выбор LLM модели (OpenRouter или локальная Ollama)
- **Temperature** — креативность модели (0.0 - строгий, 2.0 - креативный)
- **Max Tokens** — максимальное количество токенов в ответе
- **System Prompt** — кастомный системный промпт для агента
- **Skills** — навыки, доступные этому агенту
- **Context Compression** — сжатие контекста для экономии токенов

### Глобальные навыки (Global Skills)

Глобальные навыки доступны всем агентам в pipeline. Добавьте их в секции **"Global Skills"** в верхней части редактора.

### Сохранение и экспорт

- **Save** — сохранить pipeline в памяти браузера
- **Export** — экспортировать pipeline как JSON файл
- **Import** — импортировать pipeline из JSON файла
- **Run Pipeline** — запустить pipeline (требует реализации API)

## Как использовать Skill Manager

### Что такое навыки (Skills)?

Навыки — это переиспользуемые инструкции и шаблоны, которые агенты могут загружать и использовать во время выполнения задач. Каждый навык описывается в формате SKILL.md.

### Создание нового навыка

1. Перейдите на вкладку **Agents**
2. Переключитесь на вкладку **Skill Manager**
3. Нажмите **"+ Create Skill"**
4. Заполните форму:
   - **Name** — уникальное имя навыка (например, "code-review")
   - **Category** — категория (опционально, например, "development")
   - **Description** — краткое описание
   - **Content** — содержимое навыка в формате Markdown

### Формат SKILL.md

```markdown
## Что это за навык?

Описание навыка и его возможностей.

## Как использовать

1. Шаг 1
2. Шаг 2
3. Шаг 3

## Примеры

```python
# Пример кода
print("Hello, World!")
```

## Формат вывода

Ожидаемый формат результата.
```

### Управление навыками

- **Редактирование** — наведите на навык и нажмите иконку карандаша
- **Удаление** — наведите на навык и нажмите иконку корзины
- **Использование** — навыки автоматически доступны агентам в Agent Constructor

## Быстрый старт: Preset Pipelines

Для быстрого начала работы используйте готовые preset'ы:

### Simple Summary (по умолчанию)
Нажмите кнопку **"Simple Summary"** чтобы создать pipeline для быстрого суммирования текста:
- Использует навык "Simple Summary"
- Один агент-суммаризатор
- Экономит токены (max 500)
- Идеально для новичков

### Quick Analysis
Нажмите кнопку **"Quick Analysis"** чтобы создать pipeline для анализа контента:
- Classifier — определяет тип контента
- Analyst — предоставляет insights
- Использует context compression

## Примеры использования

### Пример 1: Pipeline для анализа кода

1. **Classifier** — определяет тип кода (frontend/backend/DB)
2. **Analyst** — анализирует код на уязвимости
3. **Researcher** — ищет best practices для данного типа кода
4. **Validator** — проверяет рекомендации аналитика
5. **Synthesizer** — создаёт итоговый отчёт
6. **Summarizer** — суммирует отчёт до ключевых пунктов

### Пример 2: Pipeline для исследования рынка

1. **Router** — определяет домен (tech/finance/healthcare)
2. **Analyst** (несколько параллельно) — анализирует каждый домен
3. **Researcher** — глубокое исследование с историческими данными
4. **Synthesizer** — объединяет анализ в стратегический отчёт
5. **Summarizer** — executive summary для руководства

## Советы

1. **Начинайте с малого** — создайте простой pipeline из 2-3 агентов
2. **Используйте пресеты** — в Agent Constructor есть предустановленные конфигурации для разных ролей
3. **Экономьте токены** — используйте context compression для больших входных данных
4. **Тестируйте** — экспортируйте pipeline и тестируйте его на разных входных data
5. **Документируйте** — добавляйте описания к каждому шагу для понимания workflow
