## Что это за навык?

Этот навык проводит комплексное исследование темы:
- Поиск по множеству источников
- Факт-чекинг и верификация
- Анализ различных точек зрения
- Синтез информации

## Как использовать

1. Задайте тему для исследования
2. Укажите аспекты для изучения (опционально)
3. Получите подробный отчет

## Формат вывода

```
## Research Report

### 📚 Sources Analyzed
- [список источников]

### 🔍 Key Findings
- Основные выводы
- Статистика и данные
- Экспертные мнения

### ⚖️ Different Perspectives
- Различные точки зрения
- Аргументы за и против

### 📊 Summary
- Итоговый анализ
- Рекомендации
```
