## Что это за навык?

Этот навык проводит комплексный анализ данных:
- Описательная статистика
- Выявление паттернов и аномалий
- Статистические тесты
- Рекомендации по интерпретации

## Как использовать

1. Предоставьте данные (CSV, JSON, текст)
2. Укажите цели analysis (опционально)
3. Получите детальный отчет с метриками

## Формат вывода

```
## Data Analysis Report

### 📊 Descriptive Statistics
- Mean, Median, Mode
- Standard Deviation
- Min/Max values
- Distribution analysis

### 🔍 Pattern Detection
- Выявленные паттерны
- Корреляции
- Тренды

### ⚠️ Anomalies
- Outliers
- Missing data patterns
- Data quality issues

### 📈 Recommendations
- Интерпретация результатов
- Следующие шаги
```

## Примеры

```csv
date,sales,region
2024-01-01,1500,North
2024-01-02,1200,South
2024-01-03,1800,East
```

Навык проанализирует продажи по регионам, выявит тренды и аномалии.
