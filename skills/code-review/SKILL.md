## Что это за навык?

Этот навык проводит автоматический ревью кода, проверяя:
- Потенциальные уязвимости безопасности
- Стиль кода и best practices
- Производительность и оптимизации
- Читаемость и поддерживаемость

## Как использовать

1. Отправьте код на ревью
2. Укажите язык программирования (опционально)
3. Получите детальный отчет с рекомендациями

## Формат вывода

Отчёт пиши по-русски, на языке пользователя, даже если код и комментарии в нём на английском.

```
## Ревью кода

### 🔴 Критичные проблемы
- [список критических проблем]

### 🟡 Предупреждения
- [предупреждения]

### 🟢 Рекомендации
- [рекомендации по улучшению]

### Безопасность
- [проверка безопасности]

### Производительность
- [анализ производительности]
```

## Примеры

```python
# Пример кода для ревью
def get_user_data(user_id):
    query = f"SELECT * FROM users WHERE id = {user_id}"
    return db.execute(query)
```

Этот код будет проверен на SQL-инъекции и другие уязвимости.
